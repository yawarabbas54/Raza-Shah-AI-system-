# Production integration checklist

## 1. Browser
Implement a dedicated worker around Playwright. Expose only typed actions such as:
- open_allowed_url
- click_known_selector
- fill_known_field
- extract_text
- take_screenshot

Add domain allowlists, timeouts and human confirmation before submissions.

## 2. Files
Connect storage/file APIs through an allowlist. Do not expose arbitrary filesystem paths to the model.

## 3. Long-running autonomy
Use a job queue and persistent database:
goal → plan → step → tool call → result → verification → next step.

## 4. Memory
Separate:
- session memory
- user-approved long-term preferences
- task artifacts

Give users visibility and deletion controls.

## 5. Security
Add authentication, rate limiting, CSRF protection where applicable, secret management, audit logging, sandboxing and least-privilege tool credentials.

## 6. Determinism
The model chooses among tools, but each tool validates its own schema. Never execute arbitrary shell/code generated by the model.

## 7. Proactivity
Use explicit triggers and user-defined goals. Proactive actions should be bounded, explainable and cancellable.
